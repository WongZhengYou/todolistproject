# 📌 Project Title

> to-do-list system help you to memorize what you should do. This system is to help those where can't memorize what they should do next and finally end up on swipping tiktok.

---

## 📖 Description

This system is a simple To-Do List web applications that helps users to manage their daily tasks efficiently by using a very basic CRUD operations and clean UI, this system is for those everyday use excuse to go swipping tiktok instagram, and finally forgot what is their main objective. This system also is my first practice system so dont be too mean to me pls.


---

## 🚀 Features

* ✅ Add tasks
* ✔️ Complete Task
* ❌ Delete Task

---

## 🛠️ Tech Stack

List the technologies used:

* Language: Java
* Framework: Spring MVC
* Frontend: JSP / HTML / CSS
* Build Tool: Maven
* Server: Jetty / Tomcat

---

## ⚙️ Installation

Step-by-step setup instructions:

```bash
# Clone repository
git clone https://github.com/WongZhengYou/todolistproject.git

# Navigate into project
cd project-path

# Build project
mvn clean install
```

---

## ▶️ Usage

How to run and use the project:

```bash
mvn jetty:run
```

Then open in browser:

```
http://localhost:8080/
```
